# SmartFactory Hardware & Environment Constraints

## Edge Device

- Raspberry Pi 4 Model B, 4GB RAM, 32GB microSD
- Debian Bookworm (64-bit)
- ~2GB RAM available after OS and core services

## Connectivity

- Ethernet (primary) or WiFi to factory LAN
- No internet required for operation
- Modbus RTU via USB RS-485 adapter (up to 32 devices per bus)

## Environment

- Operating temperature: -20C to +60C
- IP54-rated enclosures minimum
- DIN rail mounted in electrical cabinet
- 24V DC power supply (industrial standard)
- Must handle vibration from nearby machinery
