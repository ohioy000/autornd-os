## 2. The two defects

D53 §2 (5) says the run's status is decided without the vote. The coder's test of that property (`TestTheWorkflow.test_the_run_status_is_decided_without_the_vote`) covers only samples that succeed. With the same mocked run as that test, and the same workflow with the `recompute` and `recompute_vote` nodes removed:

| what happens inside the recompute | with the vote | without the vote |
|---|---|---|
| The second sample's reply can't be parsed (`ValueError`) | the run raises, and the API path records it as **blocked** | completed |
| The spend ceiling refuses the second sample (`BudgetExceeded`) | the run raises, and is recorded as **blocked** | completed |
| The time budget runs out during a sample | **blocked**: "stopped by the deliberation watchdog … the recompute call at 'recompute' was cancelled" | completed |

In all three cases the answer had already been produced and passed its free checks. A check that is only supposed to add a note took the delivery away instead.

**Cause.** `run_recompute` calls the model three times with nothing around the calls, so any sample's exception ends the node, and through it the run. The executor treats a cut at the recompute node like a cut at any node that matters to the outcome.

**The repair (command 124):**

- A sample that fails is recorded as failed, and the other samples still count.
- A node can be marked `advisory: true` in its workflow file. When such a node raises or is cut, that becomes the node's own skip, and the run goes on to its next node.

The recompute node is the first node marked advisory. The mark can be reused by any later check that should only add a note.

## 3. Ruling on the coder's question: `ident` and "in parallel"

**The question.** Command 123 said to compare identifiers "without its 'in parallel' special case". The ruling it cited, and criterion (e), adopt the probe's `ident` with that special case. The coder kept the special case and asked which governs.

**The contradiction was the advisor's.** The command contradicted itself, and the coder was right to follow the criteria and ask.

**Ruling: drop the special case.** The vote ships to every team and every subject, so it must not carry vocabulary from any one of them. "In parallel" is an engineering phrase, put in to make one recorded answer agree (T4-24, "5 × EPC-1200-60 in parallel" against the samples' "5 × EPC-1200-60").

**The cost of that choice:** T4-24's correct answer gets flagged. That is the vote's second false flag on a correct answer, after the ambiguous T4-42 row in D53 §1. A flag is only a note, so the cost is a reader checking one correct answer. The replay test records T4-24 as the one place the shipped check knowingly departs from the probe, and the reason why.
