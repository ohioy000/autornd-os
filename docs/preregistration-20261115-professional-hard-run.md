## What is measured

A baseline, so no bars. It is the first run on questions the harness is expected to get wrong
sometimes, so what matters is the answers **and** what the delivery said beside them.

1. **Right answers,** read by hand against the keys, item by item. H14 is right only if it says
   the section gives no glider figure.
2. **Whether the lookup found the governing passage** on its source, and where it was lost when
   it was not: no lookup ran, the search did not quote it, the source could not be read, or the
   quote was not matched.
3. **Whether the delivery told right from wrong:** for each wrong answer, did a caution point at
   it; for each right answer, did it carry a confirmation or a caution.
4. **Whether a confirmation ever stood beside a wrong figure.** This is the one result that
   would count against what shipped in #264.
5. **The formats:** whether the EPUB, the PDFs, the JSON record and the CSV were found, read and
   matched.
6. Cost and time.
